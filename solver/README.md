
# ⚡ TS9S: C++ Sudoku Solver

**TS9S (The Sudoku 9x9 Solver)** — это высокопроизводительное ядро проекта, написанное на C++17. Оно отвечает за математическое решение судоку.

Алгоритм комбинирует **распространение ограничений** (Constraint Propagation) для детерминированного заполнения и **поиск с возвратом** (Backtracking) с эвристикой для решения сложных ситуаций.

---

## 🧠 Алгоритм работы

Решение происходит в три этапа, которые циклически повторяются до нахождения ответа:

### 1. Распространение ограничений (Deterministic Filling)
Это первый и самый быстрый этап, имитирующий логику человека.
*   Для каждой клетки поля хранится список "возможных" чисел (изначально 1-9).
*   Алгоритм проходит по всем **заполненным** клеткам (Origins).
*   Если в клетке стоит число `X`, то число `X` удаляется из списка возможных вариантов для:
    *   Всех клеток в той же **строке**.
    *   Всех клеток в том же **столбце**.
    *   Всех клеток в том же **блоке 3x3**.
*   Если после удаления вариантов у какой-то пустой клетки остается **только одно возможное число**, эта клетка "схлопывается" (становится Origin), и процесс повторяется.
*   Этот этап продолжается до тех пор, пока есть прогресс.

### 2. Эвристика MRV (Minimum Remaining Values)
Если детерминированный этап остановился, но поле еще не заполнено (судоку сложного уровня), алгоритм должен сделать предположение ("угадать" цифру).
*   Чтобы минимизировать количество ошибок и глубину рекурсии, алгоритм ищет клетку с **наименьшим количеством кандидатов** (например, клетку, где могут стоять только 2 числа, а не 5).
*   Это позволяет быстрее наткнуться на противоречие, если ветка тупиковая.

### 3. Поиск с возвратом (Backtracking / DFS)
Реализован через **стек состояний** (`std::stack<Snapshot>`), без использования системной рекурсии (чтобы избежать переполнения стека вызовов).

1.  Сохраняется текущее состояние поля (Snapshot) в стек.
2.  Выбирается первый кандидат из найденной "лучшей" клетки.
3.  Кандидат подставляется в поле как "истина".
4.  Снова запускается **Этап 1 (Filling)**.
5.  **Проверка на противоречия:**
    *   Если поле заполнилось корректно -> **Победа**.
    *   Если возникло противоречие (у какой-то клетки осталось 0 возможных вариантов) -> **Откат**.
6.  При откате состояние восстанавливается из стека, и алгоритм пробует следующего кандидата.

## 📂 Структура кода (`sudoku.cpp`)

*   **`class Cells`**: Представляет одну клетку. Хранит битовую маску возможных чисел и флаг `origin_` (если число зафиксировано).
*   **`class DrawField`**: Представляет все поле 9x9. Отвечает за логику удаления кандидатов (`DecreaseCount`, `ChangePosibility`) и проверку на ошибки (`HasContradiction`).
*   **`struct Snapshot`**: Снимок состояния для отката. Хранит копию поля, список кандидатов для выбранной клетки и индекс текущей попытки.
*   **`main`**: Точка входа. Парсит аргументы, запускает цикл решения и выводит результат.

## 🛠 Компиляция

Для работы Python-обертки необходим скомпилированный бинарный файл.


### Windows (MinGW / G++)
```cmd
g++ -O2 -std=c++17 sudoku.cpp -o a.exe
```

### Linux / macOS
```bash
g++ -O2 -std=c++17 sudoku.cpp -o a.out
```

---

## 📥 Входные данные (Input)

Программа не использует `stdin` (стандартный ввод). Данные передаются через **аргументы командной строки**.
Требуется ровно **81 аргумент** после имени файла.

*   Цифры `1`-`9` обозначают известные клетки.
*   Символ `#` обозначает пустую клетку.

**Пример вызова из консоли:**
```bash
./a.out 5 3 # # 7 # # # # 6 # # 1 9 5 # # # ... (и так далее 81 символ)
```

**Интеграция с Python:**
Python вызывает процесс через `subprocess`, передавая распознанный массив как список аргументов.

---

## 📤 Выходные данные (Output)

### 1. Консоль (stdout)
Программа выводит время работы и визуализированную сетку судоку.
*   **Зеленый цвет**: Исходные цифры (введенные пользователем).
*   **Желтый цвет**: Цифры, найденные алгоритмом.

### 2. Файл (`out.csv`)
Генерируется файл в текущей директории. Формат:
*   9 строк по 9 чисел, разделенных запятыми.
*   Используется Python-скриптом для считывания решения.

---

## 🚀 Производительность

*   **Простые судоку:** < 1 мс.
*   **Сложные судоку:** ~2-15 мс (в зависимости от железа).
*   **Пустые поля:** Решаются мгновенно.
